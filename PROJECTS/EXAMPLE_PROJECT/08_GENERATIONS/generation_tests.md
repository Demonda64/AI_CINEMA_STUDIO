# Generation Tests

Ce document enregistre les essais de prompts, les variantes testées et les évaluations de qualité.

## Test 1 : style de station vide

### Prompt
Station de métro futuriste vide, nuit profonde, néons bleus froids, sol humide, ambiance mélancolique. Grosses surfaces métalliques, affiches usées, reflets légers, calme pesant.

### Résultats attendus
- Atmosphère nocturne et vide
- Texture humide et métallique
- Absence de foule

### Notes
- Vérifier le niveau de détail sur les reflets.
- Ajuster si l'image est trop saturée ou trop propre.

## Test 2 : découverte du message

### Prompt
Main prenant un message manuscrit dans un casier de métro, lumière chaude concentrée sur le papier, fond diffus et ombres profondes, émotion contenue.

### Résultats attendus
- Mise au point sur la main et le message
- Texture du papier visible
- Contraste froid/chaud

### Notes
- Éviter les arrière-plans numériques trop prononcés.
- Favoriser une sensation tactile.

## Test 3 : flashs du passé

### Prompt
Souvenirs flous d'une femme dans un cadre urbain nocturne, teintes chaudes, bokeh léger, nostalgie, mouvement doux.

### Résultats attendus
- Style onirique et doux
- Couleurs chaudes filtrées
- Sensation de mémoire

### Notes
- Ajuster la clarté pour ne pas perdre l'émotion.
- Tester plusieurs niveaux de flou.
