# Generation Prompts

## Prompt général de style
Sujet : station de métro futuriste, nuit presque vide.
Action : un agent de transit trouve un message manuscrit dans un casier.
Atmosphère : mélancolique, mystérieuse, intimiste.
Caméra : plan serré sur les mains, plan large sur le quai vide, contre-plongée sur les néons.
Éclairage : néons bleus froids, points de chaleur jaune orangé, ombres profondes.
Détails : textures métalliques, reflets humides, affiches usées, surfaces polies.
Négatif : éviter les scènes trop saturées, les arrière-plans encombrés, l'éclairage uniforme.

## Prompt scène 1
Sujet : quai de métro désert.
Action : Simon marche lentement le long du quai en inspectant les écrans.
Atmosphère : silence pesant, solitude.
Caméra : plan large pour montrer l'absence, puis plan serré sur son visage.
Éclairage : néons bleus, couches de reflets légers.
Détails : pluie fine sur le sol, écrans éteints, fumée légère.
Négatif : éviter les couleurs chaudes intenses, les foules.

## Prompt scène 2
Sujet : main découvrant un message manuscrit.
Action : Simon sort une feuille pliée d'un casier.
Atmosphère : surprise douce, émotion contenue.
Caméra : gros plan sur les doigts, profondeur de champ réduite.
Éclairage : lumière chaude sur le papier, contrastes doux autour.
Détails : texture du papier, écriture à la main, petites gouttes de condensation.
Négatif : éviter les éléments numériques visibles, les couleurs vives excessives.

## Prompt scène 3
Sujet : flashs du passé.
Action : Simon se souvient d'une amie et d'une promesse.
Atmosphère : nostalgie, chaleur fragile.
Caméra : plans légèrement flous, retour d'image.
Éclairage : tons chauds, arrière-plans doux.
Détails : silhouettes précises, lumières diffuses, mouvement lent.
Négatif : éviter les flashs blancs, les couleurs saturées, le chaos visuel.
