# Generations

Le projet de génération IA doit viser la cohérence visuelle et l'ambiance nocturne.

### Prompts recommandés
- Scène 1 : station de métro futuriste vide, néons bleus, personnages isolés, ambiance mélancolique.
- Scène 2 : gros plan sur une main tenant un message manuscrit, textures de papier et lumière chaude.
- Scène 3 : flashs oniriques du passé avec teintes chaudes et silhouettes floues.

### Itérations
1. Test de style visuel.
2. Ajustement de l'ambiance lumière.
3. Variation de l'émotion et de la composition.

### Notes
- Inclure des détails de texture pour renforcer la crédibilité.
- Préserver un style cohérent entre les scènes.
