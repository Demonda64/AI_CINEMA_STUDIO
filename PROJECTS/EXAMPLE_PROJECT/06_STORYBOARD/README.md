# Storyboard

Le storyboard doit suivre la progression émotionnelle de Simon.

### Séquence clé
- Plan d'ouverture sur le quai désert.
- Découverte du message dans le casier.
- Flashs émotionnels de son passé.
- Traversée des couloirs de la gare.
- Plan de départ vers la banlieue.

Objectif : garder un rythme lent, introspectif et une intensité croissante.
