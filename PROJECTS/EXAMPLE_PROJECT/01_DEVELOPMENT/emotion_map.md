# Emotion Map

Ce document suit l'évolution émotionnelle de Simon à travers les scènes.

## Ligne émotionnelle

- Scène 1 : solitude froide, isolement.
- Scène 2 : curiosité retenue, souffle de surprise.
- Scène 3 : nostalgie, douceur fragile.
- Scène 4 : tension intérieure, hésitation.
- Scène 5 : espoir silencieux, décision.
- Scène 6 : ouverture vers l'avenir.

## Arc par scène

1. Station vide
   - Émotion : ennui et distance.
   - Besoin : sens, connexion.
   - Décision : rester ou bouger.

2. Boîte aux souvenirs
   - Émotion : surprise contenue.
   - Besoin : compréhension.
   - Décision : ouvrir le passé.

3. Réminiscence
   - Émotion : chaleur douce, regret.
   - Besoin : réparation.
   - Décision : accepter le souvenir.

4. Recherche
   - Émotion : tension, détermination.
   - Besoin : preuve.
   - Décision : agir malgré la peur.

5. Rencontre
   - Émotion : espoir et fragilité.
   - Besoin : proximité.
   - Décision : poursuivre la piste.

6. Dernier passage
   - Émotion : calme décidé.
   - Besoin : conclusion ouverte.
   - Décision : partir vers l'inconnu.

## Observations

- Le récit doit rester centré sur l'intériorité de Simon.
- La progression émotionnelle doit être lisible sans dialogue excessif.
- Les moments de silence doivent être porteurs de sens.
