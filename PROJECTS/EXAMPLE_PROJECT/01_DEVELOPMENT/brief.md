# Brief de projet

> Ce brief de projet est un exemple d'application du modèle `PROJECTS/_PROJECT_TEMPLATE/brief_template.md` et doit être utilisé avec `HOME/agents_workflow.md`.

## 1. Informations générales

- Titre projet :
Dernier Passage
- Logline :
Un agent de transit découvre un message oublié dans une station de métro nocturne et doit décider s'il part à la recherche de la personne qui l'a écrit.
- Genre :
Science-fiction dramatique
- Durée cible :
12 minutes
- Format :
Court métrage
- Public cible :
Amateurs de drames contemplatifs et d'esthétique néo-noir

## 2. Vision créative

- Thème principal :
Mémoire et rédemption
- Emotion principale :
Mélancolie porteuse d'espoir
- Ton général :
Intimiste, silencieux, légèrement mystérieux
- Ambiance :
Nuit urbaine, station de métro désertée, lumière froide ponctuée de chaleur
- Style visuel souhaité :
Neo-noir minimaliste avec contrastes froid/chaud et plans motivés par l'émotion

## 3. Informations narratives

- Concept clé :
Un message oublié relance un personnage dans sa recherche d'une deuxième chance.
- Message / idée centrale :
Le passé peut encore être rattrapé si on décide d'agir.
- Arc principal du protagoniste :
Du détachement à la décision, puis à l'espoir d'une rencontre.
- Conflit central :
Le choix entre rester dans la routine sécurisante ou suivre un indice vers l'inconnu.
- Structure souhaitée :
3 actes courts avec 6 scènes clés

## 4. Personnages principaux

- Protagoniste :
  - Nom :
  Simon
  - Description :
  Agent de transit nocturne, discret, méthodique, en retrait émotionnellement.
  - Objectif :
  Trouver la personne qui a laissé le message.
  - Besoin émotionnel :
  Reconnexion, réparation, espoir.

- Antagoniste / obstacle :
  - Nom :
  La peur de l'échec et le confort de la routine
  - Description :
  Force interne qui retient Simon dans sa zone de confort.
  - Enjeux :
  Le risque de rester seul face à sa culpabilité.

- Personnages secondaires :
  - Nom(s) :
  Léa (amie disparue / souvenir), collègues de station
  - Fonction dans l'histoire :
  Léa est la raison émotionnelle et narrative du voyage intérieur.

## 5. Monde et univers

- Type d'univers :
Métropole futuriste légèrement usée
- Lieux clés :
Station de métro vide, bureau de transit, gare de banlieue
- Atmosphère du monde :
Froid, silencieux, technique, mais chargé de mémoire
- Contraintes ou règles du monde :
Technologie avancée mais dominante, vie humaine rare la nuit

## 6. Identité visuelle et sonore

- Palette de couleurs :
Bleus froids, gris métalliques, accents orange chaud
- Style de caméra :
Plans serrés, mouvements lents, quelques travellings motivés
- Ambiance lumière :
Néons froids, contrastes profonds, points de chaleur ponctuels
- Style sonore :
Ambiances urbaines subtiles, nappes synthétiques, silence chargé
- Références visuelles / sonores :
Films néo-noir, station de métro nocturne, musique ambient douce

## 7. Besoins de génération IA

- Objectifs de génération :
Créer des visuels atmosphériques de la station, des gros plans texturés et des flashs oniriques.
- Types de visuels attendus :
Scène de métro vide, découverte du message, souvenirs flous.
- Niveau de détail :
Élevé sur les textures et l'ambiance, modéré sur les personnages.
- Contraintes techniques :
Palette cohérente, état nocturne, style néo-noir.
- Prompt initial :
Station de métro futuriste vide la nuit, néons bleus, sol humide, ambiance mélancolique.
- Prompt négatif :
Éviter les couleurs saturées, les foules, les arrière-plans encombrés.

## 8. Contraintes de production

- Délais :
Prototype livré en 2 semaines
- Budget approximatif :
Faible / production légère
- Ressources disponibles :
Décors intérieurs, petits lieux urbains, IA pour les visuels
- Contraintes techniques :
Accessibilité en image de synthèse, 1080p
- Format de livraison :
Markdown pour documentation, MP4 pour vidéo finale

## 9. Priorités créatives

- Ce qui est indispensable :
Atmosphère mélancolique, cohérence visuelle, émotion de rédemption.
- Ce qui peut être flexible :
Le nombre exact de scènes, les personnages secondaires.
- Ce qui doit être évité :
Les couleurs vives, les actions trop spectaculaires, les explications lourdes.

## 10. Notes et références

- Références visuelles :
Stations de métro modernes, film noir urbain, néons.
- Références sonores :
Ambiances de gare, synth wave légère.
- Inspirations narratives :
Histoires d'isolement et de réconciliation.
- Remarques complémentaires :
Le projet doit rester centré sur l'intime et le silence intérieur.
