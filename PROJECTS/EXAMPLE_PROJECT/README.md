# EXAMPLE_PROJECT

Ce projet sert de démonstration du flux de production AI CINEMA STUDIO.
Il illustre un pipeline complet, de la development à l'archive.

Pour utiliser cet exemple :
- Copier la structure de `PROJECTS/_PROJECT_TEMPLATE/` pour un nouveau projet.
- Étudier `01_DEVELOPMENT/brief.md` comme modèle de brief aligné au workflow.
- Se référer à `HOME/agents_workflow.md` pour comprendre le passage de Phase 0 à Phase 4.
- Vérifier les listes de fichiers et le découpage des livrables dans chaque phase.
- Consulter `01_DEVELOPMENT/emotion_map.md` pour suivre l'arc émotionnel.
- Consulter `06_STORYBOARD/storyboard_plan.md` et `07_SHOTS/shot_list.md` pour des livrables de planning visuel.
- Consulter `11_POST/post_production_notes.md` et `12_EXPORTS/export_report.md` pour les livrables finaux.

Mini-checklist pour suivre cet exemple :
1. Ouvrir `01_DEVELOPMENT/brief.md` et comparer avec `PROJECTS/_PROJECT_TEMPLATE/brief_template.md`.
2. Lire `02_PREPRODUCTION/scene_list.md` et `02_PREPRODUCTION/synopsis.md` pour voir la structure narrative.
3. Vérifier les notes de `03_WORLD_BUILDING`, `04_CHARACTERS` et `05_ENVIRONMENTS` sur l'univers et les personnages.
4. Examiner `06_STORYBOARD/storyboard_plan.md` et `07_SHOTS/shot_list.md` pour le découpage visuel et les plans.
5. Consulter `08_GENERATIONS/generation_prompts.md` et `08_GENERATIONS/generation_versions.md` pour l'approche IA.
6. Parcourir `09_AUDIO/README.md`, `10_EDITING/README.md`, `11_POST/post_production_notes.md` et `12_EXPORTS/export_report.md` pour les phases finales.
7. Utiliser `13_ARCHIVE/postmortem.md` comme modèle d'archivage final et de bilan.
