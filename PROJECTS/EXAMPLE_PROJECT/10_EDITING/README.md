# Editing

Le montage doit faire ressentir la progression interne de Simon.

### Stratégie
- Début lent et posé.
- Accent sur les détails et les silences.
- Accélération émotionnelle aux moments de découverte.
- Fin ouverte avec un plan long et contemplatif.

### Transitions
- Coupes motivées entre le réel et les flashs.
- Fondus courts vers les souvenirs.
- Transitions sonores pour lier l'espace du métro et la gare.
