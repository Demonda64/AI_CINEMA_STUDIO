# World Building

Le projet se déroule dans une métropole futuriste légèrement usée : tubes de métro modernes, néons fatigués, écrans de surveillance et espaces désertés.

La nuit transforme la ville en un paysage presque désert, où les rares passants semblent loin et insaisissables.

Les règles du monde :
- La technologie est avancée mais froide.
- Les interactions humaines sont rares.
- Le métro est un lieu de transition entre le quotidien et l'intime.
