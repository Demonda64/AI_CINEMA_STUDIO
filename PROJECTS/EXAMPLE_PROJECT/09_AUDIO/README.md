# Audio

Le design sonore soutient l'intimité et la tension nocturne.

### Palette sonore
- Ambiance : souffle de ventilation, gouttes d'eau lointaines, bourdonnement de néon.
- Musique : nappes synthétiques subtiles, progression douce.
- Effets : cliquetis métalliques, sons de pas lointains.

### Moments clés
- Arrivée dans la station : silence pesant et réverbération.
- Découverte du message : crescendo léger de résonance.
- Départ vers la gare : ouverture sonore vers l'extérieur.
