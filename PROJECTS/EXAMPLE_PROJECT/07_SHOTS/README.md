# Shot Plan

Le plan de tournage doit privilégier l'intimité et la texture.

### Exemple de shots
- Gros plan sur les mains de Simon découvrant le message.
- Plan large de la station vide pour souligner la solitude.
- Plan par-dessus l'épaule sur l'écran de surveillance.
- Plan tracking lent le suivant dans les couloirs.
- Contre-plongée sur la gare d'arrivée, ouverture vers l'extérieur.

Objectif : des plans motivés par l'émotion et le mouvement intérieur.
