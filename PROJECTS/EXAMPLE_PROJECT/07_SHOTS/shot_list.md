# Shot List

Ce document décrit les plans principaux et leur intention.

## Plan 1 : Quai désert
- Type : plan large.
- Objectif : installer la solitude et l'espace.
- Mouvement : travelling lent.

## Plan 2 : Simon marche
- Type : plan moyen / plan américain.
- Objectif : montrer le personnage dans son environnement.
- Mouvement : travelling suivant.

## Plan 3 : Découverte du message
- Type : gros plan.
- Objectif : concentrer l'attention sur le geste.
- Mouvement : légère caméra fixe pour l'intensité.

## Plan 4 : Flashs du passé
- Type : plans rapprochés.
- Objectif : suggérer la mémoire et l'émotion.
- Mouvement : légers flous et dézooms.

## Plan 5 : Recherche dans la gare
- Type : inserts et plans d'ensemble.
- Objectif : montrer l'intensité de la quête.
- Mouvement : plans de suivi et coupes motivées.

## Plan 6 : Dernier passage
- Type : plan long.
- Objectif : donner un sentiment d'ouverture.
- Mouvement : éventuel travelling arrière ou steady.
