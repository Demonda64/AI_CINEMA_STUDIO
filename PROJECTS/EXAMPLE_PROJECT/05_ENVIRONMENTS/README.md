# Environments

## Station de métro
- Atmosphère : froide, silencieuse, presque déserte.
- Éléments : néons, écrans vides, casiers, quais déserts.

## Bureau de transit
- Atmosphère : fonctionnel, rétro-tech.
- Éléments : moniteurs, archives, lumière fluorescente.

## Gare de banlieue
- Atmosphère : fragile, animée par quelques voyageurs.
- Éléments : panneaux, affiches, lumière diffuse du matin.
