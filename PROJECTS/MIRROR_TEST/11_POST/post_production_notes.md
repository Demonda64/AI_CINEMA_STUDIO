# Notes de post-production - Phase 4

Ces notes cadrent les premières décisions de post-production pour l'animatic et la version finale.

## Image

- Conserver la palette bleu-gris.
- Ne pas pousser les noirs jusqu'au bouché complet.
- Garder le rouge du réveil discret.
- Éviter les effets de glitch visibles sur le miroir.
- Ajouter un grain léger seulement si toutes les images restent cohérentes.

## Stabilisation / mouvement

Pour l'animatic :
- utiliser de très légers zooms lents sur les images fixes ;
- éviter les mouvements trop visibles ;
- privilégier l'immobilité pour le miroir.

Pour les futurs plans vidéo :
- mouvement lent et contrôlé ;
- pas de caméra portée excessive ;
- aucun tremblement artificiel au moment de la révélation.

## Son

- Alarme sèche au départ.
- Vibration téléphone courte, isolée.
- Room tone continu mais discret.
- Basse non musicale à partir du miroir.
- Respiration optionnelle, jamais trop démonstrative.

## Transitions

- Cuts secs pour l'intrusion.
- Fondus très courts pour l'installation du miroir.
- Fondu au noir final possible.

## Export animatic

Paramètres recommandés :
- Format : MP4
- Ratio : 16:9
- Framerate : 24 fps ou 25 fps
- Résolution : 1920x1080 pour validation
- Audio : stéréo, niveau modéré
