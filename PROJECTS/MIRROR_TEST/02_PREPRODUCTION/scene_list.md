# Scene List

## Scène 1 : Le réveil
- **Durée estimée** : 30 secondes
- **Lieu** : Chambre à coucher
- **Personnages** : L'homme seul
- **Objectif** : Établir la routine, l'agacement, le contrôle (débrancher l'alarme)
- **Émotion clé** : Irritation
- **Détails visuels** : Réveil digital affichant 3h17, main qui débranche, darkness autour

## Scène 2 : Le message
- **Durée estimée** : 20 secondes
- **Lieu** : Chambre, sur le lit ou debout
- **Personnages** : L'homme, présence invisible (message)
- **Objectif** : Intrusion, perte de contrôle
- **Émotion clé** : Confusion, malaise
- **Détails visuels** : Téléphone vibre, message sur écran, visage du protagoniste réagit

## Scène 3 : La recherche
- **Durée estimée** : 45 secondes
- **Lieu** : Chambre, salle de bain (brève)
- **Personnages** : L'homme
- **Objectif** : Chercher la source, vérifier la réalité
- **Émotion clé** : Anxiété croissante
- **Détails visuels** : Mouvements de caméra nerveux, vérifications inutiles, retour à la chambre

## Scène 4 : Le miroir
- **Durée estimée** : 1 minute
- **Lieu** : Chambre, face au miroir
- **Personnages** : L'homme et la présence (reflet anormal)
- **Objectif** : Révélation, choc final
- **Émotion clé** : Horreur totale
- **Détails visuels** : Approche du miroir, réalisation progressive, moment de rupture

## Scène 5 : L'après (optionnel, ambigu)
- **Durée estimée** : 15 secondes
- **Lieu** : Chambre
- **Personnages** : L'homme, la présence
- **Objectif** : Acceptation du nouvel état
- **Émotion clé** : Résignation horrifiée
- **Détails visuels** : Fin ouverte, regard fixe, silence

---

## Notes de progression narrative

- **Tempo** : Lent au début, accélération vers la fin
- **Pas de dialogue** ou dialogue très minimaliste (juste le message texte, pas d'explication)
- **Sensori-moteur** : L'alarme, la vibration, la respiration du protagoniste sont les "bruits du film"
- **Ambiguïté** : Aucune explication offered. Le reflet peut être hallucination, doubling, ou vraie présence.
