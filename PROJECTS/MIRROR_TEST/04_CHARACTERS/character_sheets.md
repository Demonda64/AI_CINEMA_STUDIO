# Character Sheets

## Personnage principal : L'homme (sans nom)

**Description physique** :
- Âge : 25-35 ans
- Apparence : Fatigué, traits neutres, corps ordinaire
- Vêtements : Pyjama simple, couleurs sombres
- Particularités : Cernes sous les yeux, mouvements hésitants après le réveil

**Psychologie** :
- Trait dominant : Perfectionniste/anxieux (besoin de contrôle)
- Motivation : Récupérer le contrôle de sa vie/sommeil
- Peur : L'invasion de son espace privé
- Besoin : Comprendre ce qui se passe

**Backstory** (implicite) :
- Souffre d'insomnie chronique ou d'une malédiction (la routine du 3h17)
- Vit seul dans un environnement urbain
- Isolé, peu de relations sociales
- Avant le film : routine établie, acceptation passive du problème
- Pendant le film : tentative de reprendre le contrôle (débrancher l'alarme)

**Désir vs Besoin** :
- Désir : Dormir sans interruption
- Besoin : Accepter que certaines choses échappent au contrôle

**Arc émotionnel** :
- Début : Agacement, contrôle
- Milieu : Confusion, perte de contrôle
- Fin : Horreur, résignation

**Aucun dialogue attendu** : Le personnage s'exprime par ses gestes, expressions faciales, respiration.

---

## Entité / Présence : "Le Reflet" ou "L'Autre"

**Nature** (ambigüe) :
- Peut être : hallucination, doubling, présence paranormale, ou simple reflet anormal
- Le film ne révèle jamais la vérité

**Caractéristiques** :
- Silhouette humaine mais légèrement "off"
- Regarde directement
- Peut sourire ou faire une expression vague
- Immobile ou mouvement minimaliste

**Rôle** :
- Antagoniste implicite
- Force de l'horreur sans explication
- Catalyseur de la terreur du protagoniste

**Interaction** :
- Jamais de dialogue
- Présence silencieuse
- Communication uniquement par le message texte (indirect)
