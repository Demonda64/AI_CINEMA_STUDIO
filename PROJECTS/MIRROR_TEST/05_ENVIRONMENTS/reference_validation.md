# Validation des références visuelles et sonores - Phase 2

Ce document valide les références créatives de "Mirror" avant le passage en Phase 3. Les références ci-dessous ne doivent pas être copiées littéralement : elles servent à cadrer le ton, la lumière, le rythme et le traitement sonore.

## Décision finale

**Références visuelles et sonores validées** : oui.

Le film doit rester dans une direction réaliste, nocturne, minimaliste et psychologique. L'horreur doit venir d'une anomalie progressive du réel, pas d'une esthétique spectaculaire.

---

## Références visuelles validées

### 1. Chambre nocturne réaliste

**À retenir** :
- Chambre simple, peu décorée.
- Palette bleu-gris désaturée.
- Ombres lisibles, jamais entièrement noires.
- Sources motivées : réveil, téléphone, lampe faible, salle de bain.

**Usage dans le projet** :
- Scènes 1 à 3.
- Installation de la fatigue, de l'isolement et du besoin de contrôle.

**Critère d'acceptation** :
- L'image doit sembler plausible avant d'être inquiétante.

### 2. Reflet anormal minimaliste

**À retenir** :
- Anomalie d'abord subtile : posture, regard, léger retard ou sourire ambigu.
- Miroir visible avant la révélation, mais sans attirer trop tôt l'attention.
- Présence humaine ou quasi humaine, jamais monstrueuse.

**Usage dans le projet** :
- Scène 4 et plan final optionnel.

**Critère d'acceptation** :
- Le spectateur doit d'abord douter, puis comprendre qu'il y a rupture.

### 3. Gros plans de visage en lumière d'écran

**À retenir** :
- Téléphone comme source froide.
- Visage partiellement éclairé.
- Yeux et respiration comme moteurs émotionnels.

**Usage dans le projet** :
- Scène 2, après le message.
- Scène 4, pendant l'approche du miroir.

**Critère d'acceptation** :
- La peur doit être lisible sans dialogue.

### 4. Salle de bain froide et clinique

**À retenir** :
- Blanc froid, lumière dure.
- Espace plus réel, presque trop normal.
- Contraste avec la chambre plus douce et obscure.

**Usage dans le projet** :
- Scène 3, recherche de la source.

**Critère d'acceptation** :
- La salle de bain doit donner une fausse impression de rationalité.

## Références sonores validées

### 1. Silence domestique tendu

**À retenir** :
- Le silence n'est jamais vide.
- Room tone très bas.
- Micro-bruits amplifiés : draps, pas, souffle, câble, écran.

**Usage dans le projet** :
- Toute la durée du film.

**Critère d'acceptation** :
- Le spectateur doit écouter l'espace comme s'il pouvait révéler quelque chose.

### 2. Alarme sèche et irritante

**À retenir** :
- Son banal, répétitif, légèrement trop fort.
- Coupure brutale après débranchement.
- L'alarme représente la routine et le contrôle.

**Usage dans le projet** :
- Scène 1, possible rappel final si le cycle doit être suggéré.

**Critère d'acceptation** :
- L'alarme doit agacer avant d'inquiéter.

### 3. Vibration du téléphone comme intrusion

**À retenir** :
- Vibration nette, courte, isolée.
- Aucun son de notification reconnaissable.
- Elle doit interrompre le silence plus violemment que l'alarme.

**Usage dans le projet** :
- Scène 2.

**Critère d'acceptation** :
- Le son doit faire sentir que l'espace privé vient d'être traversé.

### 4. Respiration comme arc émotionnel

**À retenir** :
- Respiration faible au départ.
- Plus présente après le message.
- Instable devant le miroir.

**Usage dans le projet** :
- Scènes 2 à 5.

**Critère d'acceptation** :
- L'évolution de la respiration doit remplacer le dialogue.

### 5. Basse non musicale

**À retenir** :
- Fréquence grave très discrète.
- Pas de mélodie.
- Pas de montée orchestrale.

**Usage dans le projet** :
- À partir de la Scène 3, surtout Scène 4.

**Critère d'acceptation** :
- La basse doit être ressentie plus qu'entendue.

---

## Références rejetées

- Jump scare sonore.
- Présence monstrueuse ou effet gore.
- Éclairage rouge dominant.
- Musique de suspense classique.
- Voix, chuchotements ou explication surnaturelle.
- Caméra trop agitée pendant toute la recherche.
- Décor trop chargé ou trop stylisé.

---

## Consignes pour Phase 3

Les prompts IA devront privilégier :
- `minimalist nocturnal bedroom`
- `blue gray desaturated palette`
- `dim practical lighting`
- `digital alarm clock 3:17`
- `cold phone screen light on tired face`
- `large mirror with subtle abnormal reflection`
- `psychological horror`
- `realistic domestic interior`
- `ambiguous human presence`

Les prompts négatifs devront exclure :
- monstres explicites
- sang
- gore
- lumière néon agressive
- couleurs saturées
- décor gothique
- jump scare
- visage déformé de façon caricaturale

## Validation finale

La Phase 2 peut être considérée comme validée pour le passage aux prompts de génération IA.
