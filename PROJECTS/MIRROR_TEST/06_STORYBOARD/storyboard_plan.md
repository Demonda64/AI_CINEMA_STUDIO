# Storyboard Plan - Phase 2

Ce plan traduit la structure narrative de Phase 1 en progression visuelle. Il sert de base au découpage, aux prompts de génération et au montage.

## Règle de mise en scène

Chaque scène doit rapprocher le spectateur d'une vérité qu'il ne veut pas voir. Le film commence avec des plans lisibles et contrôlés, puis glisse vers des cadres plus serrés, plus silencieux, plus suspects.

## Scène 1 : Le réveil

**Objectif visuel** : établir la routine et l'agacement.

### Plan 1.1 - Chambre nocturne
- Type : plan large fixe.
- Cadre : lit, table de nuit, réveil digital visible.
- Action : l'homme dort mal, presque déjà réveillé.
- Émotion : fatigue.
- Note : le décor doit être calme, ordinaire, sans menace explicite.

### Plan 1.2 - Réveil digital
- Type : insert très serré.
- Cadre : affichage `3:17`.
- Action : l'alarme sonne.
- Émotion : irritation immédiate.
- Note : le rouge digital doit être le premier accent coloré fort.

### Plan 1.3 - Main qui débranche
- Type : gros plan main / câble / interrupteur.
- Cadre : geste sec, familier.
- Action : il coupe l'alarme.
- Émotion : reprise de contrôle.
- Note : le geste doit sembler répété depuis longtemps.

## Scène 2 : Le message

**Objectif visuel** : casser le contrôle immédiatement après le geste.

### Plan 2.1 - Silence après l'alarme
- Type : plan moyen sur l'homme assis au bord du lit.
- Cadre : dos ou trois-quarts, téléphone proche.
- Action : il respire, croit avoir gagné le silence.
- Émotion : soulagement fragile.

### Plan 2.2 - Téléphone qui vibre
- Type : insert téléphone.
- Cadre : écran s'allume dans le noir.
- Action : message inconnu.
- Texte : "Tu aurais dû le laisser branché."
- Émotion : malaise.

### Plan 2.3 - Réaction visage
- Type : gros plan.
- Cadre : visage éclairé par téléphone.
- Action : lecture, incompréhension, regard vers la pièce.
- Émotion : confusion.

## Scène 3 : La recherche

**Objectif visuel** : transformer la chambre en espace suspect.

### Plan 3.1 - Scan de la chambre
- Type : caméra portée lente.
- Cadre : coins de la chambre, porte, sol, table de nuit.
- Action : il cherche une présence.
- Émotion : anxiété.

### Plan 3.2 - Couloir ou salle de bain
- Type : plan subjectif ou semi-subjectif.
- Cadre : porte entrouverte, lumière froide.
- Action : il avance puis s'arrête.
- Émotion : doute.

### Plan 3.3 - Retour chambre
- Type : plan moyen plus serré.
- Cadre : l'homme revient dans la chambre, le miroir est visible mais secondaire.
- Action : il ne trouve rien.
- Émotion : anxiété frustrée.
- Note : placer le miroir dans le cadre sans attirer toute l'attention.

## Scène 4 : Le miroir

**Objectif visuel** : révéler le point de non-retour.

### Plan 4.1 - Première anomalie
- Type : plan moyen avec miroir.
- Cadre : l'homme au premier plan, reflet en arrière-plan.
- Action : un décalage minime dans le reflet.
- Émotion : inquiétude nette.
- Note : l'anomalie doit être presque contestable.

### Plan 4.2 - Approche
- Type : travelling lent ou avancée portée très stable.
- Cadre : l'homme s'approche du miroir.
- Action : il vérifie si le reflet suit.
- Émotion : peur montante.

### Plan 4.3 - Révélation
- Type : gros plan miroir / visage.
- Cadre : le reflet ne correspond plus.
- Action : la présence regarde directement, peut-être sourit.
- Émotion : horreur.
- Note : pas de jump scare. Le malaise vient de la certitude progressive.

## Scène 5 : L'après

**Objectif visuel** : laisser une trace, pas une explication.

### Plan 5.1 - Chambre immobile
- Type : plan large fixe, similaire au premier.
- Cadre : lit, miroir, silence.
- Action : l'homme reste figé ou sort du cadre.
- Émotion : résignation.

### Plan 5.2 - Dernier reflet
- Type : insert ou plan serré miroir.
- Cadre : présence encore là, ambiguë.
- Action : presque rien.
- Émotion : doute persistant.

## Notes de continuité visuelle

- L'affichage `3:17` doit être parfaitement lisible dans la Scène 1.
- Le téléphone doit être près de l'homme avant de vibrer.
- Le miroir doit exister visuellement avant la révélation, sans devenir trop évident.
- La présence ne doit jamais être expliquée par un effet trop démonstratif.
