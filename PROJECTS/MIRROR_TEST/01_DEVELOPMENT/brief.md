# Brief de projet

> Ce brief du projet MIRROR_TEST applique le modèle `PROJECTS/_PROJECT_TEMPLATE/brief_template.md` et s'aligne avec `HOME/agents_workflow.md`.

## 1. Informations générales

- Titre projet : Mirror
- Logline : Un homme se réveille à 3h17 chaque nuit et découvre que quelqu'un l'observe dans son miroir—une présence qui refuse de disparaître.
- Genre : Thriller psychologique / Horreur subtile
- Durée cible : 4-5 minutes
- Format : Court métrage
- Public cible : Amateurs de thrillers psychologiques minimalistes et ambiance oppressante

## 2. Vision créative

- Thème principal : L'invasion de l'intimité et le doute de la réalité
- Emotion principale : Terreur silencieuse, malaise croissant
- Ton général : Tendu, minimaliste, viscéral
- Ambiance : Chambre à coucher isolée, nuit profonde, tension stérile
- Style visuel souhaité : Réalisme naturel avec légère surexposition ou couleurs désaturées, effet de présence omniprésente

## 3. Informations narratives

- Concept clé : L'alarme qui revient, le message, la révélation du miroir
- Message / idée centrale : On n'est jamais seul, même dans les moments les plus privés
- Arc principal du protagoniste : Du sommeil disturé à la réalisation horrifiante, final ambigu
- Conflit central : Réalité vs. paranoia, intérieur vs. extérieur, solitude vs. présence
- Structure souhaitée : Trois actes courts (intro-crescendo-choc)

## 4. Personnages principaux

- Protagoniste :
  - Nom : Sans nom (l'homme)
  - Description : Jeune adulte, fatigué, routine nocturne établie
  - Objectif : Dormir, puis comprendre ce qui se passe
  - Besoin émotionnel : Sécurité, compréhension, contrôle

- Antagoniste / obstacle :
  - Nom : La présence (l'entité dans le miroir)
  - Description : Force invisible, intelligente, malveillante ou simple reflet ?
  - Enjeux : La santé mentale, l'identité, la réalité du protagoniste

- Personnages secondaires :
  - Potentiel : Personne d'appel (voix, intercom) ou seulement présence absente

## 5. Monde et univers

- Type d'univers : Réaliste contemporain, avec un élément paranormal/surréel
- Lieux clés : Chambre à coucher, salle de bain, miroir
- Atmosphère du monde : Isolé, urbain silencieux, la nuit comme ennemi
- Contraintes ou règles du monde : Les règles normales de réalité commencent à se briser

## 6. Identité visuelle et sonore

- Palette de couleurs : Bleu-gris nocturne, blanc cru du miroir, accents de noir profond
- Style de caméra : Plans larges de la chambre, gros plans du visage, plans directs au miroir, POV subjective
- Ambiance lumière : Lumière naturelle minimale, affichage digital du réveil (3:17), reflets du miroir
- Style sonore : Silence oppressant, alarme stridente, vibration du téléphone, respiration du protagoniste, bruit blanc
- Références visuelles / sonores : Horreur minimaliste, thriller psychologique, tension type "Insomnia" ou "The Machinist"

## 7. Besoins de génération IA

- Objectifs de génération : Créer des images de chambre minimaliste la nuit, reflet anormal dans le miroir, tension visuelle
- Types de visuels attendus : Chambre vide, miroir avec ombre/silhouette, expression du visage du protagoniste
- Niveau de détail : Élevé sur les textures nocturnes et les reflets, modéré sur le personnage
- Contraintes techniques : Palette cohérente, pas de distorsion exagérée (subtilité)
- Prompt initial : Chambre moderne minimaliste la nuit, 3h17 sur un réveil digital, miroir au mur, ombre inexplicable dans le reflet, ambiance terrifiante et silencieuse
- Prompt négatif : Éviter l'horreur gore, les couleurs vives, les distorsions démoniaques exagérées, les peurs classiques (zombies, fantômes clairs)

## 8. Contraintes de production

- Délais : Prototype livré en 1 semaine (test rapide)
- Budget approximatif : Minimal / production intime
- Ressources disponibles : Chambre minimale, miroir, réveil digital, IA pour visuels
- Contraintes techniques : 1080p ou 4K selon capacité
- Format de livraison : Markdown pour documentation, MP4 pour vidéo finale

## 9. Priorités créatives

- Ce qui est indispensable : La tension du message, le reflet anormal, l'ambiance oppressante
- Ce qui peut être flexible : Le nombre exact de cuts, la durée précise, les sons additionnels
- Ce qui doit être évité : Horreur explicite, explications lourdes, résolution claire (final doit rester ambigu)

## 10. Notes et références

- Références visuelles : Thrillers minimalistes, chambres d'hôtel vides, reflets de miroir, éclairage nocturne
- Références sonores : Silence tendu, alarmes stridents, respiration amplifiée
- Inspirations narratives : Expériences de paranoia, intrusion dans l'espace privé, présence invisible
- Remarques complémentaires : Le projet teste la pipeline en mode "sprint court" avec un concept minimal mais intense
