# Emotion Map

Progression émotionnelle du protagoniste à travers le film.

## Avant le début (implicite)
- Émotion : fatigue chronique
- Cause : alarme récurrente toutes les nuits

## Scène 1 : L'alarme à 3h17
- Émotion : agacement, irritation
- Action : débranchement de l'alarme
- Besoin : silence, contrôle

## Scène 2 : Le message inconnu
- Émotion : confusion, intrigue, early malaise
- Action : vérification du téléphone
- Besoin : compréhension, explanation

## Scène 3 : L'inspection de la chambre
- Émotion : anxiété croissante
- Action : recherche de la source
- Besoin : sécurité, certitude

## Scène 4 : Face au miroir
- Émotion : horreur complète, choc émotionnel
- Action : confrontation avec le reflet anormal
- Besoin : fuite, ou acceptation de la présence

## Fin (ambigu)
- Émotion : résignation horrifiée, acceptation du doute
- État : basculement vers un nouvel ordre émotionnel

## Notes de progression

- La montée est constante, presque sans pause.
- Pas de répit émotionnel : chaque élément amplifie le précédent.
- Le climax (miroir) doit être le point de rupture totale.
- L'absence de résolution garde le spectateur en tension.
