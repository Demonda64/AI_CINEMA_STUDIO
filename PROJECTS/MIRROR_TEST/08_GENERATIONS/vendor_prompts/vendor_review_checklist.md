# Checklist de revue vendors

Cette checklist sert à valider rapidement les sorties ElevenLabs, HeyGen et Grok avant intégration au montage.

## HeyGen - Vidéo

### Validation générale

- [ ] Le plan respecte la durée cible.
- [ ] La palette reste bleu-gris, froide et désaturée.
- [ ] La chambre reste minimaliste et compatible avec les images sélectionnées.
- [ ] Le mouvement reste lent et contrôlé.
- [ ] Aucun jump scare.
- [ ] Aucun monstre, gore ou effet surnaturel explicite.
- [ ] Le reflet reste humain et subtil.
- [ ] Le fichier peut être intégré au montage MP4.

### S04-P01

- [ ] Le reflet semble presque normal au début.
- [ ] L'anomalie devient lisible par regard/posture, pas par déformation.
- [ ] Le plan garde le doute.

### S04-P04

- [ ] Le regard direct est inquiétant.
- [ ] Le sourire reste léger.
- [ ] La révélation n'est pas trop théâtrale.

## ElevenLabs - Audio

- [ ] L'alarme est courte, sèche et irritante.
- [ ] La vibration est physique et non mélodique.
- [ ] Le room tone reste très discret.
- [ ] La respiration est organique mais pas trop dramatique.
- [ ] La basse miroir n'est pas musicale.
- [ ] Aucun cri, voix, chuchotement ou effet démonstratif.
- [ ] Les fichiers sont propres, sans artefacts audibles trop marqués.
- [ ] Les niveaux peuvent être mixés sans saturation.

## Grok - Analyse / Prompting

- [ ] Les recommandations respectent l'ambiguïté.
- [ ] Les prompts ne rendent pas l'horreur trop explicite.
- [ ] Les variantes restent compatibles avec le storyboard.
- [ ] Les notes proposent des corrections actionnables.
- [ ] Aucune proposition ne contredit les références validées.

## Intégration

- [ ] Copier les fichiers retenus vers `08_GENERATIONS/assets/video/selected/` ou `09_AUDIO/assets/selected/`.
- [ ] Mettre à jour `vendor_versions.md`.
- [ ] Mettre à jour `asset_inventory.md`.
- [ ] Mettre à jour `animatic_export_report.md` si un nouvel export est produit.
- [ ] Mettre à jour `phase_checklist.md`.
