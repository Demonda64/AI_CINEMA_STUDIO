# Packet ElevenLabs - Batch audio principal

## Objectif

Générer les cinq sons principaux pour remplacer ou améliorer les sons temporaires du mix v03.

## Paramètres généraux

- Style : réaliste, domestique, minimaliste.
- Genre : horreur psychologique subtile.
- À éviter : musique, jump scare, cris, voix démonstrative.
- Format préféré : WAV.
