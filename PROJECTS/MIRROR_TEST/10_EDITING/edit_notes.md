# Notes de montage - Phase 4

Ces notes ouvrent la phase de montage et post-production pour "Mirror".

## Intention de montage

Le montage doit préserver l'ambiguïté. Il ne doit pas expliquer ce qui arrive, seulement organiser la progression : routine, intrusion, recherche mentale, confrontation, résignation.

La version animatic lot 01 est une maquette de tension, pas encore le film complet.

## Structure de montage cible

| Segment | Durée cible | Fonction |
|---------|-------------|----------|
| Réveil | 30s | Routine et agacement |
| Message | 20s | Intrusion impossible |
| Recherche | 45s | Perte de contrôle |
| Miroir | 60s | Révélation progressive |
| Après | 15s | Fin ouverte |

**Durée cible finale** : 4-5 minutes avec respiration, transitions et sons.

## Version animatic lot 01

La première version animatic utilise uniquement les assets retenus de Phase 3 :

- S01-P02 : réveil `3:17`
- S02-P03 : message texte
- S04-P01 : première anomalie
- S04-P04 : révélation
- S05-P02 : fin ouverte

Cette version sert à tester :
- la lisibilité des informations clés ;
- le contraste alarme/message/miroir ;
- la durée nécessaire pour que le reflet devienne inquiétant ;
- la pertinence de produire des plans de transition supplémentaires.

## Plans complémentaires recommandés

Pour passer d'un animatic court à une version plus complète, générer ou produire :

1. S01-P01 : plan large de chambre.
2. S01-P03 : visage fatigué au réveil.
3. S01-P04 : main qui débranche l'alarme.
4. S02-P04 : réaction au message.
5. S03-P01 : inspection de la chambre.
6. S03-P04 : salle de bain froide.
7. S04-P02 : approche du miroir.

## Règles de coupe

- Ne pas accélérer les plans de miroir trop tôt.
- Laisser les inserts lisibles.
- Couper le son avant de couper l'image lorsque la tension doit monter.
- Garder au moins une respiration complète avant la révélation S04-P04.
- Ne pas finir sur un effet sonore agressif.

## Risques

- Animatic trop elliptique si aucun plan de transition n'est ajouté.
- Message trop explicite si le plan reste trop longtemps après lecture.
- Reflet trop clair si le montage insiste trop sur S04-P04.
- Rythme trop rapide pour une horreur psychologique.
