# PROJECT TEMPLATE

Ce dossier contient le modèle standardisé pour créer un nouveau projet dans AI CINEMA STUDIO.

## Fichiers importants du template

### Guides de démarrage
- **`quick_start.md`** : Guide pas à pas pour démarrer un nouveau projet.
- **`brief_template.md`** : Template du brief de projet à compléter.
- **`phase_checklist.md`** : Checklist pour valider chaque phase (Phase 0 à Phase 4).

### Configuration du projet
- **`project_overview.md`** : Vue d'ensemble du projet.
- **`audio_world.md`** : Définition du monde audio.
- **`camera_rules.md`** : Règles de caméra et de cadrage.
- **`lighting_rules.md`** : Règles d'éclairage.
- **`visual_philosophy.md`** : Philosophie visuelle du projet.
- **`emotion_map.md`** : Carte émotionnelle par scène.

## Comment utiliser ce template

1. **Copier la structure complète** : dupliquez le dossier `_PROJECT_TEMPLATE` et renommez-le avec le nom de votre projet.
2. **Compléter le brief** : ouvrez et remplissez `brief_template.md`.
3. **Utiliser la checklist** : copiez `phase_checklist.md` dans votre projet et utilisez-la pour valider chaque phase.
4. **Suivre le workflow** : utilisez `HOME/agents_workflow.md` en parallèle pour orchestrer les agents.
5. **Se référer à l'exemple** : consultez `PROJECTS/EXAMPLE_PROJECT/` pour voir un projet complet.

## Structure de dossiers

```
PROJECTS/<NomDuProjet>/
├── 01_DEVELOPMENT/
├── 02_PREPRODUCTION/
├── 03_WORLD_BUILDING/
├── 04_CHARACTERS/
├── 05_ENVIRONMENTS/
├── 06_STORYBOARD/
├── 07_SHOTS/
├── 08_GENERATIONS/
├── 09_AUDIO/
├── 10_EDITING/
├── 11_POST/
├── 12_EXPORTS/
├── 13_ARCHIVE/
├── brief.md (copie de brief_template.md, complétée)
├── phase_checklist.md (copie du template, remplie au cours du projet)
└── ... (autres fichiers de configuration)
```
