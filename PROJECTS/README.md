# PROJECTS

Contient tous les films et productions.

Chaque projet possède : développement, préproduction, storyboard, shots, audio, montage, exports, archive.

Modèle de projet : `PROJECTS/_PROJECT_TEMPLATE`.
- Utiliser `PROJECTS/_PROJECT_TEMPLATE/brief_template.md` pour standardiser le brief de projet.
- Suivre `HOME/agents_workflow.md` pour aligner chaque livraison sur le pipeline d'agents.

Règle : chaque projet doit être autonome et complet.

Guides utiles :
- `PROJECTS/_PROJECT_TEMPLATE/brief_template.md` pour le brief standardisé.
- `PROJECTS/_PROJECT_TEMPLATE/quick_start.md` pour démarrer rapidement un nouveau projet.
- `PROJECTS/EXAMPLE_PROJECT/` comme projet modèle montrant la structure et les livrables.
